# fixtures — 테스트용 샘플 디자인 프로젝트

목업(`docs/mockup`)의 «my-shop» 데이터로 만든 `freegma/` 폴더 두 벌. **골든 파일**이다 — `packages/core/src/golden.test.ts`가 파일마다 «스키마 통과 + 다시 쓰면 바이트가 같다»를 검사한다.

| 폴더 | 플랫폼 · 스펙 | 내용 |
|---|---|---|
| `web-basic/freegma/` | 웹 · React + Tailwind, React Router | 도메인 3(홈·상품·주문), 화면 3(`/`, `/products/:id`, `/cart`), 시안 1, 디자인 시스템(토큰 6파일·글자 스타일 5·기본 컴포넌트 4 + 서비스 컴포넌트 3) |
| `mobile-basic/freegma/` | 모바일 앱 · React Native, Expo Router | 같은 구성, 모바일 크기(393×852)·글자 단계(13·15·17·22·28) |

## 고칠 때
- 직접 고쳐도 되지만, 결과는 반드시 `serialize()`가 내는 모양과 바이트까지 같아야 한다(키 순서·2칸 들여쓰기·기본값 생략·끝 줄바꿈 1개 — spec §5). 틀리면 골든 테스트가 실패한다.
- 토큰·컴포넌트·시안 원본·이미지 참조가 실제로 있어야 한다(골든 테스트의 «서로 맞는다» 검사).
- Biome 포매터는 이 폴더를 건드리지 않는다(`biome.json`에서 제외).
